# Licences

- `MIT.txt`: this repository's own files (picks, scripts, gates, index tooling, our first-party items) unless a file says otherwise.
- `Apache-2.0.txt`, `OFL-1.1.txt`: reference copies of licences used by vendored material.

Every vendored item keeps its upstream licence file next to the copy (see `THIRD_PARTY.md` for the full list with commits). Link-only picks are not copied here at all.
